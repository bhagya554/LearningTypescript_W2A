# LearningTypescript_W2A

TypeScript learning exercises, organized by day.

## Structure

```
src/
  Day1/
    1_HelloWorld.ts        # hello world
    2_Variables.ts         # var, let, const
    3_DataTypes.ts         # basic data types
    4_StringType.ts        # string type
  Day2/
    5_number_primitive.ts     # number
    6_boolean_primitive.ts    # boolean
    7_undefined_primitive.ts  # undefined
    8_null_primitive.ts       # null
    9_any_primitive.ts        # any
  Day3/
    10_MultipleDataTypes.ts   # union types
    11_Object_Example.ts      # object type
    12_Optional_Parameter.ts  # optional parameters
    13_Array.ts               # arrays
  Day4/
    14_ArrayTopic.ts       # array methods
    15_TupleExample.ts     # tuples
    16_ControlStatements.ts # if / else
    17_Nested_IF_Else.ts   # nested if...else
    18_Ternary_Operator.ts # ternary operator
    19_Switch.ts           # switch
  Day5/
    20_ForLoop.ts          # for loop
    21_WhileLoop.ts        # while loop
    22_DoWhile.ts          # do...while loop
    23_For_Of_In_Each.ts   # for...of, for...in, forEach
  Day6/
    24_ForEachExample.ts   # forEach
    25_BreakExample.ts     # break
    26_ContinueExample.ts  # continue
```

## Setup

```bash
npm install
```

## Build

Compiles `src/` to `dist/` per `tsconfig.json`:

```bash
npx tsc
```

## Run

```bash
node dist/Day5/23_For_Of_In_Each.js
```
